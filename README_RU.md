# DOTA AI v0.2 — Windows desktop foundation

Это полноценная исходная структура Windows-приложения на Electron с NSIS installer.

## Что уже заложено

- Оверлей-окно поверх других окон.
- Трей Windows.
- Горячая клавиша `Ctrl + Shift + Space`.
- Автозапуск вместе с Windows (включён по умолчанию, настраивается в приложении).
- Локальный GSI HTTP-приёмник `127.0.0.1:3000`.
- Автоматический поиск распространённых библиотек Steam и Dota 2.
- Автоматическая запись GSI-конфига с резервной копией существующего файла.
- Локальный объяснимый rules engine для базовых подсказок.
- NSIS-конфигурация для создания установщика `DOTA-AI-Setup-0.2.0.exe`.

## Требования для сборки

- Windows 10/11 x64 (рекомендуется для финальной сборки и проверки).
- Node.js LTS и npm.
- Интернет для установки npm-пакетов.

## Запуск из исходников

```powershell

```

## Сборка Windows EXE

В PowerShell в корне проекта:

```powershell
npm install
npm run dist:win
```

Готовый установщик появится в `release/`.

Важно: текущая среда подготовки проекта не является Windows, поэтому готовый Windows EXE здесь не собран и не проверен. Исходный проект и конфигурация сборки готовы; финальную сборку нужно выполнить на Windows.

## Первый запуск и права

Приложение устанавливается в профиль пользователя без обязательных прав администратора. Если Dota 2 находится в защищённой папке и Windows запрещает запись GSI-конфига, приложение покажет ошибку. В таком случае нужно закрыть игру и предоставить разрешение на запись в папку Dota 2 либо вручную скопировать конфиг.

При первом запуске приложение:
1. Запускает локальный GSI-сервер.
2. Ищет установку Dota 2 в стандартных библиотеках Steam.
3. Создаёт `game/dota/cfg/gamestate_integration/gamestate_integration_dota_ai.cfg`.
4. При наличии старого файла делает резервную копию.
5. После запуска игры ждёт реальные данные GSI.

## Автозапуск

Используется официальный Electron API `app.setLoginItemSettings`. Настройка хранится в пользовательских настройках. При старте вместе с Windows приложение может работать в трее и не открывать окно автоматически.

## Честные ограничения этой версии

Это основа полноценного продукта, но ещё не готовый AI-тренер:
- нет проверенной матчевая аналитики на реальном GSI payload;
- нет готовых билдов предметов и контрпиков;
- нет обученной модели прогноза победы;
- нет голосового движка;
- нет автообновления с опубликованного сервера;
- нет цифровой подписи установщика;
- прозрачность поверх эксклюзивного fullscreen может отличаться; рекомендуется Borderless Window.

Приложение не управляет героем, не читает память процесса Dota 2 и не раскрывает скрытую информацию противников. Используются только данные, которые игра отдаёт через GSI.

## Архитектура

- `src/main` — Electron main process, окно, tray, горячие клавиши, IPC.
- `src/preload` — безопасный мост IPC.
- `src/renderer` — интерфейс.
- `src/integrations` — GSI сервер и обнаружение/настройка Dota 2.
- `src/core` — настройки и аналитические правила.
- `build` — ресурсы установщика.
- `scripts` — проверки проекта.

## Получить установщик через GitHub Actions

В проект добавлен workflow `.github/workflows/build-windows.yml`. Загрузите проект в свой GitHub-репозиторий, откройте Actions и запустите `Build DOTA AI Windows installer`. Подробная инструкция находится в `GITHUB_ACTIONS_RU.md`. По завершении сборки скачайте EXE из раздела Artifacts.
