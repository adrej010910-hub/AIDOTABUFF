# Как получить DOTA_AI_Setup.exe через GitHub Actions

Этот проект уже содержит workflow `.github/workflows/build-windows.yml`.
GitHub Actions соберёт Windows x64 NSIS installer на Windows runner и приложит `.exe` к результатам запуска workflow.

## Что потребуется

- Аккаунт GitHub.
- Создать пустой репозиторий на GitHub.
- Загрузить в него всё содержимое этой папки проекта, включая скрытую папку `.github`.
- Убедиться, что ветка называется `main`.

Не загружай `node_modules` или папку `release`, если они есть локально.

## Запуск сборки

1. Открой репозиторий на GitHub.
2. Перейди во вкладку **Actions**.
3. Выбери **Build DOTA AI Windows installer**.
4. Нажми **Run workflow** → выбери `main` → **Run workflow**.
5. Дождись зелёной галочки у задания `build-windows`.
6. Открой завершённый запуск workflow.
7. Внизу страницы найди **Artifacts**.
8. Скачай `DOTA-AI-Windows-Installer` — внутри будет `.exe`.

Сборка также автоматически запускается при каждом push в `main`.

## Важно

- Workflow не требует GitHub Secrets и не публикует приложение в публичный Releases.
- Готовый установщик доступен как Actions Artifact в течение 14 дней.
- Для постоянной ссылки позже можно настроить GitHub Releases.
- Установщик пока не имеет цифровой подписи издателя. Windows SmartScreen может показать предупреждение для неизвестного приложения. Не отключай защиту Windows; проверяй, что файл скачан именно из Actions этого репозитория.
- Это сборка текущей версии DOTA AI, а не подтверждение полной готовности всех AI-функций. После сборки необходимо проверить установку, автозапуск и подключение GSI на Windows.
